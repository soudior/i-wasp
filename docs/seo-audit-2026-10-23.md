- Ce script ne fait **pas** de rendu serveur du contenu React complet ; il corrige seulement le shell HTML initial et ajoute un fallback sans JavaScript.
- Vérifier le build Vercel de prévisualisation, puis lire le HTML brut de `/pricing`, `/produits`, `/features` et `/contact` sur l'URL de prévisualisation.
- Vérifier 1 canonical unique par page, 1 titre distinct, une description distincte, `og:url` aligné, les 13 URL du sitemap, et une vraie 404 pour les routes inconnues.
- Le déploiement Netlify officiel reste inchangé ; aucune modification DNS, publication sociale ou production n'est autorisée par ce brouillon.
